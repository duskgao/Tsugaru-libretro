# Tsugaru (FM Towns) - libretro core

A libretro core port of TOWNSEMU (the FM Towns / Marty emulator "Tsugaru"),
so you can run FM Towns software inside RetroArch and any libretro frontend.

Status: core name `tsugaru_libretro`, base TOWNSEMU v20260522 Pre-release.
License: BSD 3-Clause (TOWNSEMU) + MIT (libretro.h).

See `src/main_libretro/README.md` for porting notes and `浣跨敤璇存槑涔?md` for a
step-by-step beginner guide (Chinese).

Upstream: https://github.com/captainys/TOWNSEMU
